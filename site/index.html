Goobits

A Hardware Random Number Generator

Goobits is a hardware random number generator that uses ambient microphone noise as its source of entropy. Random bytes are generated continuously and either served to users or archived for statistical testing. Live statistics of recently archived bytes are available to users, and more extensive statistical analysis of archived random data is also available. Also hosted here is a public randomness beacon service inspired by NIST's randomness beacon. Each minute, a 512-bit full-entropy bit string is published as a pulse, and each pulse is hash-chained to ensure the chain is not tampered with. Learn more about the technical details of how Goobits works here.
