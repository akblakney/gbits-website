Extensive Statistical Test Results

This section is still in progress, as doing extensive statistical testing on the RNG requires large amounts of data, and also some choices about which external source code to use. At first I tried to use NIST's 800-22 test suite, but ran into some flaky tests that failed even on well-known cryptographically secure PRNGs (like the Overlapping tempalte test). Apparently this is a known bug. So I pivoted towards using this improved implementation of the NIST test suite. The following files give summary reports on the STS test done on about 1800 bit streams (of default length 2^20 bits). For refernce, I've also ran the test on the output of a state-of-the-art CSPRNG (in this case, Linux's default CSPRNG which uses ChaCha20). This way we have a baseline of what we should expect the test outputs to look like on random data. The output of the three tests on the Goobits generator give no indication of non-randomness. The overall fail rate of each bitstream was actually below that of the CSPRNG--both of them around 1.005% (compared to the expected fail-rate of 1%)--and the difference between the two being statisticall insignificant. As more data is archived by the generator I will continue to run more of these extensive tests.
